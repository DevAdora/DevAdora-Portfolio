# 👨‍💻 DevAdora — Personal Portfolio

> **Software Developer · Design & Innovation · Kabankalan City, Philippines**

A modern, full-stack personal portfolio built with **Next.js**, featuring a fully integrated **AI chatbot assistant** — so visitors can ask questions about my work, skills, and experience in real time.

---

## 🌐 Live Demo

[devadora.vercel.app](https://devadora.vercel.app)

---

## ✨ Features

- 🎨 **Cinematic Hero Section** — Full-bleed grayscale background with infinite scrolling marquee typography
- 🤖 **AI Chatbot Assistant** — Visitors can chat with an AI trained on my portfolio context to learn about my services, projects, and experience
- 🖼️ **Animated Projects Gallery** — Scroll-driven WORKS/PROJECTS marquee with sticky "Selected Works" label and per-project GitHub + Live Demo links
- 🃏 **Stacked Services Cards** — Scroll-triggered sticky cards revealing each service offering
- 👤 **About Section** — Structured personal info layout with fact table and tag pills
- 📬 **Contact Slide-in Form** — Smooth side-panel contact form with field validation
- ⚡ **Framer Motion Animations** — Page transitions, hover effects, and scroll-linked transforms throughout
- 📱 **Fully Responsive** — Optimized for all screen sizes from mobile to ultrawide

---

## 🤖 Chatbot Assistant

The portfolio includes a built-in AI assistant that knows about:

- My skills, services, and tech stack
- Projects I've built and the problems they solve
- My background, education, and work approach
- How to get in touch or hire me
